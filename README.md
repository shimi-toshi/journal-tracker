# Journal Tracker

会計・ファイナンスの主要ジャーナルから新着論文を毎日自動取得し、一覧ページとして公開するツールです。

**URL**: https://shimi-toshi.github.io/journal-tracker/

> **免責事項**: 本ページの情報は最終更新日時点で最新かつ正確な内容を掲載するよう努めていますが、誤りが含まれる可能性があります。ご利用の際は、必ず一次情報をご確認ください。
>
> **最終更新日**: 2026年6月14日

## 機能

- 上記の全誌について、CrossRef に新しく登録された論文を毎日 18 時頃（JST）に取得して一覧化
- 表示期間（1〜30日）の切り替え、タイトル・著者・アブストラクトのキーワード検索、アブストラクトの折りたたみ表示
- 誌名の横に ABDC / ABS 評価を表示
- Editorial Board などの論文以外の項目や、再登録された古い論文は新着から除外
- 長期間取得できていない誌は「新着なし」と誤解されないよう、その旨を表示

## 使い方

Python 3.10 以上が必要です。

```bash
git clone https://github.com/shimi-toshi/journal-tracker.git
cd journal-tracker
pip install -r requirements.txt
python -m src.main              # 取得して output/new_papers_YYYYMMDD.xlsx と docs/ を更新
```

| オプション | 説明 |
|---|---|
| `--dry-run` | 取得のみ行い、DB・Excel・HTMLには書き込まない |
| `--stats` | DBの統計を表示 |
| `--list-journals` | 対象ジャーナル一覧（ISSN）を表示 |
| `--self-check` | 設定・ジャーナルリスト・DB・テンプレートを診断 |
| `--config <path>` | 設定ファイルを指定（既定は `config/config.yaml`） |

Windows では `run_tracker.bat` からも実行できます。対象誌は `Accounting_Journals_URL_List.xlsx` で管理しています。

## 自動更新（GitHub Actions）

`.github/workflows/update-pages.yml` が毎日 JST 18:17 頃に実行され、`docs/`（公開ページ）と `data/`（DB・直近の実行結果）を更新します。
手動実行（workflow_dispatch）も可能です。

リポジトリの Settings → Secrets and variables → Actions に `CROSSREF_EMAIL`（連絡先メールアドレス）を登録すると、
CrossRef の polite pool が使われ、取得が安定します（未設定でも動作します）。ローカル実行時は `.env.example` を `.env` にコピーして設定します。
